# Фронтенд: технологии на Hacker News

Vite 5, React 18, TypeScript, TanStack Query, React Router 6, CSS Modules. Графики — свои, на HTML/CSS, без библиотеки.

Страницы:

| Путь | Что |
|---|---|
| `/` | поиск, сводка по выборке, рейтинг «Чаще всего в заголовках» |
| `/tech/:key` | страница технологии: вывод, ключевые числа, тон комментариев с примерами, статьи, вовлечённость (IRR), частые слова, источники, динамика (от 4 недель данных), связанные технологии, методика |

## Запуск в разработке

Нужны Node 18.14+ и запущенный API (см. `../README.md`, раздел про API):

```powershell
# терминал 1 — API
cd hackernews_project
$env:HN_DB_URL = "sqlite:///D:/hackernews_data/run_small/hn.db"
uvicorn api.main:app --reload

# терминал 2 — фронтенд
cd hackernews_project/frontend
npm install
npm run dev          # http://127.0.0.1:5173, запросы /api проксируются на 127.0.0.1:8000
```

Другой адрес API — переменная `HN_API_URL` (например, `HN_API_URL=http://10.0.0.5:8000 npm run dev`).

## Типы API

Типы ответов генерируются из OpenAPI-схемы, вручную их не правим:

```bash
npm run gen:api      # нужен запущенный API; пишет src/api/schema.d.ts
```

После изменения схем в `api/schemas.py` перегенерируйте типы и прогоните `npm run typecheck`.

## Тесты

```bash
npm test             # Vitest + Testing Library, фикстуры — реальные ответы API (src/test/fixtures)
npm run test:e2e     # Playwright: сценарий поиска и переходов, axe-проверка страниц; нужен запущенный API
```

Первый запуск E2E: `npx playwright install chromium`.

## Сборка и выкладка

```bash
npm run build        # статика в dist/
```

Содержимое `dist/` копируется в `/var/www/hackernews` (см. `.claude/README.md`, разделы 5.7 и 6.1): nginx отдаёт `index.html` для неизвестных путей, `/api/` проксирует на uvicorn, `/assets/` кэширует надолго.

## Устройство

```
src/
  api/          клиент, хуки TanStack Query, типы из OpenAPI
  components/   поиск (ARIA combobox), каркас, графики, общие блоки
  lib/          форматирование по-русски, вывод словами (summary.ts), хуки, тема
  pages/        главная, страница технологии и её блоки (pages/tech/)
  styles/       токены (цвета, типографика, движение) и глобальные стили
```

Правила, которые держим:

- **Ненадёжное не выдаём за результат.** При `reliable=false` значение не показывается, вместо него пояснение «мало данных» с числом наблюдений; в вывод над цифрами такие метрики не попадают.
- **Цвета данных** — только из токенов `--data-bar`, `--sent-pos/neu/neg`; палитра проверена на контраст и различимость при нарушениях цветового зрения в обеих темах. Значения всегда подписаны текстом.
- **Движение** — только обратная связь (наведение, фокус, появление списка подсказок, приглушение списка при смене сортировки), до 200 мс, через токены `--dur-*`/`--ease-*`. При `prefers-reduced-motion` отключается.
- **Тексты интерфейса** — простыми словами, без эмодзи; иконки — inline SVG.
