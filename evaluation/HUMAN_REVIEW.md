# Проверка человеком

Ни один файл в этом пакете пока не является человеческим эталоном.
Не открывайте AI-метки, модельные оценки и ошибки до завершения собственной разметки.

## Предыдущая выборка

Заполните `evaluation/human_review/blinded_sentiment.csv`:

- `label_comment`: общий тон собственных слов автора, -1 / 0 / 1.
- `label_tech`: отношение к указанной технологии, -1 / 0 / 1; пусто, если отношение
  нельзя приписать технологии. Пусто не означает нейтральный тон.
- `reviewed=1` только после проверки строки; `reviewer` — имя проверяющего,
  `reviewed_at` — дата YYYY-MM-DD, `notes` — объяснение сложного решения.
- `story_id`, `comment_id`, `tech`, `text`, `title` и `split` менять нельзя.

Критика компании, автора статьи или отдельной программы не переносится автоматически
на язык или ОС. Цитата не является мнением автора. Фактическое описание и
сбалансированная оценка относятся к нейтральному классу. Сравнение двух технологий
может означать разное отношение к каждой из них.

Импорт завершённых строк без непроверенных AI-меток:

```powershell
python -m scripts.human_review import --source evaluation/sentiment.csv --reviews evaluation/human_review/blinded_sentiment.csv --output-dir artifacts/human_review
python -m scripts.evaluate_supervised_sentiment --input artifacts/human_review/human_only.csv --output-dir artifacts/human_sentiment_metrics
```

Если размеченных строк или классов недостаточно, обучение/оценку нельзя считать
завершёнными. Для согласованности решений полезны два независимых разметчика
и последующее согласование расхождений; не выдавайте одного разметчика за двух.

## Новая выборка

`next_review/dictionary.csv` содержит 600 новых заголовков. Сначала размечайте
только `development` (200), используя фиксированный каталог из 121 технологии;
`gold_techs` — JSON-массив ключей, в том числе `[]` для отсутствия технологий каталога.
Название вне каталога отмечайте в пояснении. Укажите автора и дату в `annotation_source`.
400 строк `holdout` отложите до фиксации следующей версии правил; не исправляйте
правила после просмотра их ошибок.

`next_review/sentiment.csv` содержит 101 длинный комментарий с заранее закреплённым
разделением по статьям. Метки пусты. Для них также можно сформировать слепой лист:

```powershell
python -m scripts.human_review prepare --source evaluation/next_review/sentiment.csv --output-dir artifacts/long_comment_review
```

`artifacts/embeddings_audit/neighbors_review.csv` позволяет отметить релевантность
соседей (`human_relevant`), имя проверяющего и пояснение. Общая категория — только
прокси и не заменяет эту оценку.
