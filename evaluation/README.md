# Данные для проверки методов

`dictionary.csv` и `sentiment.csv` содержат **AI-разметку Codex от 10.11.2026**.
Человеческая проверка не проводилась. Эти метки — предварительный ориентир для сравнения
методов, а не независимый человеческий эталон. Происхождение и пояснения сохранены в каждой строке.
Исходные тексты — публичные заголовки и комментарии Hacker News за апрель–август 2024 года.

## Заголовки

600 случайных статей отобраны независимо от результата распознавания технологий.
Исключены статьи прежней оценки и прежнего обучения bootstrap. Первые 200 случайно
выбранных статей — `development`, остальные 400 — `holdout`.

Разметчик видел заголовок и каталог из 121 технологии, без предсказаний классификатора.
`gold_techs` содержит JSON-массив канонических ключей; `[]` означает проверенный заголовок
без технологий каталога. Учитываются явные названия и однозначные инструменты экосистемы
(например, Node.js → JavaScript, Flutter → Dart); название компании само по себе не означает
упоминания её конкретной модели. Инструменты вне каталога не добавляются в знаменатель recall.

Известные ошибки прошлого этапа и development использовались для доработки правил.
SHA-256 версии словаря зафиксирован в `sampling.json` **до просмотра holdout**.
Для переносимости между Windows и Linux версия считается по исходнику с переводами
строк LF; исходные побайтовые отпечатки также сохранены. Сами правила при этом не меняются.
После просмотра holdout правила не изменяются; найденные там ошибки остаются ошибками.
Оценки development и holdout нужно считать отдельно.

## Комментарии

Новая выборка не пересекается по статьям с прежними выборками и с проверкой заголовков.
Отбор стратифицирован по шести технологиям и наличию явного упоминания. Взято до 40
комментариев с упоминанием и до 20 без него на технологию; для некоторых страт данных меньше.
Длина собственной прозы ограничена 60–650 символами, полные тексты не обрезаны.
Это выборка коротких реплик, её качество нельзя переносить на все комментарии HN или
напрямую сравнивать с метриками прежней выборки.

- `label_comment`: общий тон собственных слов автора, −1 / 0 / 1.
- `label_tech`: отношение к указанной технологии, −1 / 0 / 1; пусто, если объект оценки
  другой или отношение нельзя приписать технологии даже с учётом заголовка.
- Нейтральный класс включает фактическое описание технологии и сбалансированную оценку.
- Критика компании, автора статьи или сторонней программы не переносится автоматически
  на язык или ОС. В сравнении возможны противоположные знаки для разных технологий.
- Явные цитаты не считаются собственным мнением автора. Сарказм и неясные ссылки на
  предыдущую реплику остаются источниками ошибок AI-разметки.

Разметка выполнена без показа оценок VADER и других сравниваемых методов.
Колонка `split` закрепляет разделение по статьям: train / validation / test.
Порог и метод выбираются только на validation; test используется для итогового сравнения.
Отсутствие аспектного прогноза считается отказом от ответа и учитывается в покрытии и F1,
а не заменяется нейтральной меткой или общим тоном.
Оконный VADER ищет упоминания по тому же словарю, включая синонимы; берёт до 12 токенов
с каждой стороны. Без упоминания он также отказывается от ответа. Старый запасной переход
к тону всего комментария не используется при сравнении аспектных методов.

## Воспроизведение

Исходная база, модели, метрики и графики находятся в игнорируемой папке `artifacts/study/`.
Команды запускаются из корня проекта, с ограничением потоков BLAS/OpenMP до одного.
Ниже `DB_URL` — адрес отдельной рабочей копии базы, `TRAINING_CSV` — прежняя независимая
неразмеченная выборка для bootstrap, `OLD_SENTIMENT_CSV` — прежняя выборка оценки.
Для точного повторения обучения контекста нужна копия исходной базы **до** повторной
классификации: состав веток определяется сохранёнными связями `story_tech`. Их исходная
версия словаря указана в `sampling.json`. Сначала обучают модели на этой копии,
затем синхронизируют классификацию и пересчитывают метрики.

```powershell
python -m analytics.embeddings.scripts.evaluate_tech -i evaluation/dictionary.csv --split holdout --dictionary-sha256 (Get-Content evaluation/sampling.json | ConvertFrom-Json).frozen_dictionary_sha256 -o artifacts/study/dictionary_holdout.json
python -m scripts.train_study_models --db $env:DB_URL --exclude evaluation/dictionary.csv --exclude evaluation/sentiment.csv --exclude $env:OLD_SENTIMENT_CSV --output-dir artifacts/study/models
python -m analytics.embeddings.scripts.evaluate_sentiment -i evaluation/sentiment.csv --comments-model artifacts/study/models/context.model --titles-model artifacts/study/models/titles.model --training-input $env:TRAINING_CSV --out-csv artifacts/study/sentiment_metrics.csv --out-json artifacts/study/sentiment_metrics.json
python -m scripts.engagement_stability --db $env:DB_URL --output-dir artifacts/study/engagement
python -m analytics.embeddings.scripts.precompute --db $env:DB_URL --context-model artifacts/study/models/context.model --no-lemmatize
```

Для обучения исключаются все статьи оценки, включая train-часть разметки. Пилотные модели
перезаписывать не требуется. Bootstrap допускается к сравнению только после проверки обеих
моделей на вырожденность и проверки отсутствия пересечения обучающих и оценочных статей.
Параметры и состав обучения сохраняются рядом с моделями в `training.json`.

IRR по умолчанию считается без эмбеддингов и взаимодействий, с контролями формата статьи
и минимумом 30 статей на технологию. Временные половины, частотные пороги, отсутствие
контролей и Poisson с робастными ошибками сравниваются отдельно. Интервалы условны на
оценке дисперсии и отборе признаков; поправка на множественные сравнения не применяется.
Это наблюдаемые связи, которые не доказывают причинного влияния технологии.
